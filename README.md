# NARCISS HAIR — Demo 網站

> **本站僅供 Demo**，資料來自 Google Maps／粉專等公開來源，**非店家委託**。

## 本地開發

```bash
npm install
npm run dev
```

開啟 http://localhost:43123

## 建置

```bash
npm run build
npm start
```

## 技術棧

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- shadcn/ui

## 功能亮點

- 首訪 Demo 說明彈窗（不遮擋首屏 CTA）
- 首屏三鍵聯絡：電話 / IG / LINE
- 公開照片作品廊
- 寵物友善空間說明
- LINE 預約導流與 Google Maps 嵌入
